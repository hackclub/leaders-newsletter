### Ship PRs. Get Rewards.
 
This is a new series of YSWS programs for clubs to learn Git through pull requests.
*(See the name connection? Eh? EH!?🤭)*
 
These can be anything from quick edits to massive overhauls. Perfect for any meeting length. ⏱️
 
Check out the first two PullQuests below!👇👇👇

#### FrankenSite

Uh oh everyone, Jared has been coding. Check it out, isn't it a masterpiece? But to be serious, it's intentionally bad. Help me fix it! 🤦‍♂️ 🤦‍♀️
 
Clone the [<u>repository</u>](https://github.com/hackclub/frankensite). Have everyone in the club submit their own PRs. Merge them to see the monster you've all created. 
 
Contribute and ship before May 31st to enter the 🏆 Clubs contest 🏆! The top two clubs will earn grants to improve their clubs along with custom stickers for all of the top three!
**Note: Grant sizes depend on participation. More participation, larger prizes!*

#### Fix Hack Club

Oh, was the above program not serious enough? Here's the real stuff then. Ship pull requests to improve any Hack Club infrastructure and earn individual rewards!
 
<u>Here's how it works:</u>

- **Browse Hack Club spaces** and find something you want to improve. It can be anything from patching a bug, improving a design, adding relevant content, or something else!

    - *Example! Check out the new [<u>requirements</u>](https://boba.hackclub.com/requirements.html) page for [<u>Boba Drops</u>](https://boba.hackclub.com/requirements.html)! Submitted by Wally, the creator of this program!*

- **Find its repository** and submit a pull request.

- **If it's merged**, ship your PR for rewards! 

[<u>Fix Hack Club</u>](https://fix.hackclub.com/)

### Make Bookmarklets. Get the Club Funding. 

Bookmarklets are small JavaScript programs, stored as a browser bookmark. When clicked, they run code to modify a webpage, extract data, or whatever you want!
 
<u>There are two tiers of projects you can make:</u>

- First Tier: A bookmarklet with **2 features** and get a $5 grant 🍕

- Second tier: A bookmarklet with **5 features** and get a $10 grant 🍕


Check it out:

**[<u>Hacklet</u>](https://hacklet.hackclub.com/)**

Join the discussion:

**[<u>#hacklet</u>](https://app.slack.com/client/E09V59WQY1E/C08PJMATU8Y)**
